# External Contracts, Ecosystem Links & Assets

The Launch Website operates as a static client application that interfaces with the broader Threadly ecosystem via canonical external URLs.

---

## 1. External Outbound Endpoints

| Resource | URL Target | Context & Usage |
| :--- | :--- | :--- |
| **Android APK Releases** | `https://github.com/rashidekbal/threadly/releases` | Primary CTA in `Hero.jsx` for direct mobile APK distribution. |
| **Android Client Repo** | `https://github.com/rashidekbal/threadly` | Open source repository for the native Android application. |
| **Production TS Server** | `https://github.com/rashidekbal/threadly_server_ts` | Open source repository for the TypeScript backend. |
| **Legacy Server Repo** | `https://github.com/rashidekbal/threadlyServer` | Open source repository for the legacy Node.js backend. |
| **Admin Panel Repo** | `https://github.com/rashidekbal/threadly_admin_client`| Open source repository for the React Admin Panel. |

## 2. Showcase Static Asset Registry (`public/assets/`)
